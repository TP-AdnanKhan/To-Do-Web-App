# 📝 To-Do-Web-App

A simple and interactive To-Do application built using HTML, CSS and JavaScript.

🔗 **[Live Interactive Demo](https://tp-adnankhan.github.io/To-Do-Web-App/)**

---

## Features

- Add new tasks
- Edit existing tasks
- Delete tasks
- Mark tasks as completed
- Search tasks
- Filter tasks (All / Active / Completed)
- Dark and light mode
- Responsive UI

## What I Learned

- DOM manipulation
- Event listeners and event delegation
- Creating and updating elements dynamically
- Working with classes and UI states
- Array and string methods
- Flexbox layouts
- Handling user input

## Tech Used

- HTML
- CSS
- JavaScript
